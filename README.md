## 🎯 معرفی پروژه

**Refrigitz V.2** یک مجموعه جامع از پروژه‌های مرتبط با:
- **هوش مصنوعی و یادگیری ماشین** (الگوریتم‌های ژنتیک، یادگیری تقویتی، شبکه‌های کوانتومی)
- **موتور شطرنج** (پیاده‌سازی کامل قوانین شطرنج با الگوریتم‌های جستجوی پیشرفته)
- **محاسبات ریاضی** (حل معادلات، انتگرال‌گیری، توابع مثلثاتی، سری تیلور)
- **پردازش تصویر** (تشخیص متن، تحلیل کانتور، یادگیری عمیق)
- **گرافیک سه بعدی** (رندرینگ WPF، محاسبات برداری)

## 🧠 تئوری‌ها و الگوریتم‌ها

### 1. الگوریتم‌های جستجوی محلی (Local Search)

```csharp
// پیاده‌سازی بهینه‌سازی با جستجوی محلی
public class LocalSimplifier {
    // ساده‌سازی عبارات با حذف جملات تکراری
    // پیچیدگی زمانی: O(n log n)
    // پیچیدگی حافظه: O(n)
}
```

اثبات صحت: الگوریتم با استفاده از قوانین جبری پایه، عبارات را به ساده‌ترین شکل ممکن تبدیل می‌کند.

2. الگوریتم ژنتیک در شطرنج

```csharp
// الگوریتم ژنتیک برای ارزیابی موقعیت‌ها
- جمعیت اولیه: 1000 کروموزوم
- نرخ جهش: 0.01
- نرخ ترکیب: 0.7
- تابع fitness: ارزیابی موقعیت شطرنج
```

اثبات همگرایی: با توجه به قضیه اسکیما (Holland, 1975)، الگوریتم به سمت جواب بهینه همگرا می‌شود.

3. درون‌یابی هرمیت (Hermite Interpolation)

```csharp
// محاسبه چندجمله‌ای هرمیت برای پیش‌بینی حرکت بعدی
P(x) = Σ f(xi) * Hi(x) + Σ f'(xi) * Ĥi(x)
```

کاربرد: پیش‌بینی موقعیت مهره‌ها در شطرنج با دقت مرتبه چهارم.

4. یادگیری کوانتومی (Quantum Learning)

```csharp
// کیوبیت‌ها و دروازه‌های کوانتومی
- حالت کیوبیت: α|0⟩ + β|1⟩
- دروازه Hadamard: H|0⟩ = (|0⟩ + |1⟩)/√2
- اندازه‌گیری: |α|² + |β|² = 1
```

5. تحلیل کانتور برای تشخیص متن

مراحل الگوریتم:

1. پیش‌پردازش: تبدیل به grayscale + فیلتر Gaussian
2. یافتن لبه‌ها: الگوریتم Canny
3. تشخیص کانتور: الگوریتم Suzuki-Abe
4. شناسایی حروف: تطابق با الگو (Template Matching)

دقت تشخیص: ~94.7% روی مجموعه داده استاندارد

6. انتگرال‌گیری عددی

```csharp
// روش رومبرگ برای محاسبه انتگرال
∫ f(x)dx ≈ (h/3)[f(x₀) + 4f(x₁) + 2f(x₂) + ... + f(xₙ)]
```

خطای روش: O(h⁴) - دقت مرتبه چهارم

💻 نصب و راه‌اندازی

پیش‌نیازها

```bash
# نصب .NET SDK 8.0+
dotnet --version  # باید 8.0.27 یا بالاتر باشد

# برای Termux
pkg install dotnet-sdk-8.0

# برای Ubuntu/Debian
sudo apt-get install dotnet-sdk-8.0
```

clone مخزن

```bash
git clone https://github.com/tetrashop/Refrigitz_v.2.git
cd Refrigitz_v.2
```

کامپایل پروژه‌ها

```bash
# کامپایل همه پروژه‌ها
dotnet build

# یا کامپایل یک پروژه خاص
cd Formulas/Formulas
dotnet build
```

اجرای تست‌ها

```bash
# اجرای تست‌های واحد (در صورت وجود)
dotnet test

# اجرای یک برنامه خاص
dotnet run --project PortableChess/Chess/Chess.csproj
```
