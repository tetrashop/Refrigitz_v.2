# Refrigitz Graphic – Olympic Edition 🏆

**Refrigitz Graphic** یک برنامهٔ Windows Forms به زبان C# است که دو بخش اصلی را پوشش می‌دهد:  
1. **ترسیم اشکال دوبعدی** (کمان، خط، منحنی بزیه، بیضی، مستطیل، قلم) با امکان تبدیل‌های هندسی (انتقال، دوران، مقیاس، آینه).  
2. **تبدیل تصاویر دوبعدی به سه‌بعدی** با استفاده از نگاشت به مختصات کروی، کاهش هوشمند نقاط، و بازسازی مدل سه‌بعدی.

این نسخه (Olympic) باگ‌های بحرانی نسخهٔ اصلی را رفع کرده و بهینه‌سازی‌های پیشرفته‌ای در آن اعمال شده است.

---

## 📐 تئوری‌ها و مبانی علمی

### ۱. تبدیل مختصات دکارتی به کروی
برای ایجاد تصویر سه‌بعدی از یک تصویر دوبعدی، هر پیکسل با مختصات `(i, j)` و رنگ RGB به‌صورت یک نقطه در فضای سه‌بعدی در نظر گرفته می‌شود و به مختصات کروی `(r, θ, φ)` تبدیل می‌شود:
- `r = √(i² + j² + 1)` (فاصله شعاعی)
- `θ = arccos(z / r)` (زاویهٔ قطبی)
- `φ = arctan2(j, i)` (زاویهٔ سمتی)

سپس این نقاط بر اساس `r` و `θ` در یک تصویر جدید (با ابعاد بزرگ‌تر) بازچینی می‌شوند تا عمق شبیه‌سازی شود.

### ۲. الگوریتم برش خط کوهن–ساترلند (Cohen-Sutherland)
برای برش خطوط دوبعدی درون یک مستطیل، از این الگوریتم استفاده می‌شود که با اختصاص کدهای ۴بیتی به انتهای خط، عملیات برش را بهینه‌سازی می‌کند.

### ۳. مثلث‌بندی و نرمال‌ها
برای تشخیص سطوح و محاسبهٔ زوایا، مثلث‌هایی از نقاط همسایه ساخته می‌شود و با ضرب خارجی بردارها، نرمال سطح محاسبه می‌گردد.

### ۴. کاهش هوشمند نقاط (Intelligent Reduction)
با محاسبهٔ واریانس و چگالی نقاط در هر بعد، نقاط کم‌اهمیت‌تر حذف می‌شوند تا مدل سه‌بعدی بهینه‌تر شود.

## 🐛 باگ‌های رفع‌شده (نسبت به نسخهٔ اصلی)

- **تقسیم بر صفر** در محاسبهٔ `TetaStart` با استفاده از `Math.Atan2` به‌جای `Math.Atan`.
- **استفاده از `&` بیتی به‌جای `&&` منطقی** در شرط‌ها که باعث رفتار نادرست می‌شد.
- **فرمول نادرست `InversionTransmision`** که `yprin` را به‌روز نمی‌کرد.
- **فرمول‌های اشتباه دوران (`Rotation`, `InversionRotation`)** – فقدان `Sin` و استفادهٔ نادرست از `Cos`.
- **نشت حافظه گرافیکی** – جایگزینی `CreateGraphics()` با `using` برای اطمینان از `Dispose`.
- **بهبود مرتب‌سازی (`ImprovmentSort`)** با استفاده از `List.Sort` استاندارد به‌جای الگوریتم دستی ناقص.
- **افزودن کلاس `Interpolate`** برای حل دستگاه معادلات خطی (نیاز `Triangle`).
- **رفع خطاهای کامپایل** ناشی از رویدادهای گمشده در `Form1.Designer.cs`.

## ⚙️ نحوهٔ ساخت و اجرا

### پیش‌نیازها
- **.NET Framework 4.0** یا بالاتر (در ویندوز)
- **Mono** (برای لینوکس یا ترمکس)

### ساخت با Visual Studio
فایل `Graphic.sln` را باز کرده و پروژه را بیلد (`Build > Build Solution`) کنید.

### ساخت با ترمینال (Mono)
```bash
cd Graphic
mcs -r:System.Windows.Forms -r:System.Drawing -r:System.Data -r:System.Xml \
    -out:RefrigitzGraphic.exe *.cs Properties/*.cs
mono RefrigitzGraphic.exe
```
